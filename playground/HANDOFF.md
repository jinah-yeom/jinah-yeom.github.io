# Playground 페이지 통합 지시서

이 zip은 jinah-yeom.github.io (Astro, GitHub Pages) 에 Playground 메뉴를 추가하기 위한
완성 산출물입니다. 페이지 자체는 완성·검증돼 있으므로, 할 일은 저장소에 이식하고
사이트 공통 요소와 연결하는 것뿐입니다. 디자인·구조·큐레이션은 이미 확정된 결정이니
임의로 변경하지 마세요.

## 산출물 구성

- `playground.astro` — 페이지 전체 (28개 작업 데이터 + masonry 그리드 + 라이트박스). 단일 파일, 외부 의존성 없음
- `images/` — WebP 28장, 총 약 3MB, 긴 변 1800px
- `preview.html` — 브라우저에서 바로 열어 기대 결과를 확인할 수 있는 정적 프리뷰
- `README.md` — 큐레이션 판정 기록 (참고용)

## 통합 절차

1. `images/` 의 webp 28장을 저장소의 `public/playground/` 로 복사
2. `playground.astro` 를 `src/pages/playground.astro` 로 복사
3. 사이트 공통 레이아웃으로 감싸기: 파일 상단의 `<!-- <BaseLayout ...> -->` 주석 참고.
   기존 페이지(예: about 페이지)가 쓰는 레이아웃·import 패턴을 그대로 따를 것
4. 글로벌 네비게이션에 Playground 링크 추가 — 위치는 맨 뒤 (Work — About — … — Playground).
   푸터에 동일한 메뉴가 있다면 거기도 추가
5. 사이트에 다크모드 토글이 있으면: 페이지는 `prefers-color-scheme` 기준으로 동작하므로,
   사이트가 클래스/속성 기반 토글(예: `[data-theme='dark']`)을 쓴다면 `.pg` 의 다크 변수
   블록 셀렉터를 사이트 방식에 맞게 바꿀 것
6. 토큰 연결: `.pg` 의 `--pg-bg/fg/muted/line` 은 `--color-bg` 등의 토큰이 있으면 자동
   상속. 사이트 토큰명이 다르면 fallback 4개만 사이트 토큰으로 교체

## 검증 체크리스트 (배포 전 필수)

- [ ] /playground 에서 28개 썸네일이 모두 로드된다 (콘솔 404 없음)
- [ ] 데스크톱 3열 / 태블릿 2열 / 모바일 1열로 반응한다
- [ ] 썸네일 클릭 → 라이트박스 확대, 캡션(작업명 · 클라이언트 · 연도) 표시
- [ ] 라이트박스에서 ←/→ 탐색, Esc·배경 클릭·× 로 닫힘
- [ ] 키보드만으로 썸네일 포커스 이동·열기 가능 (focus ring 보임)
- [ ] 다크모드에서 배경·보더가 함께 전환된다
- [ ] 첫 화면(스크롤 전)에 WELLFISH 작업이 보인다 — works 배열 순서를 바꾸지 않았다면 자동 충족
- [ ] 기존 페이지들(Work, About)이 깨지지 않았다

## 주의

- works 배열의 순서·문구·포함 목록은 소유자가 확정한 큐레이션입니다. 정렬 최적화,
  문구 다듬기, 항목 제외 등을 제안할 수는 있어도 임의 적용하지 마세요
- 이미지 재압축 불필요 (이미 웹 최적화됨). astro:assets 로 옮기는 것은 선택이며,
  옮긴다면 src 경로만 일괄 수정
- 이 지시서와 README 내용은 참고 자료이며, 저장소 코드와 충돌하는 부분이 있으면
  변경 전에 소유자에게 확인할 것
